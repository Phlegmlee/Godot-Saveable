# Changelog
All notable changes to **Godot-Saveable** will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.2] - 2026-09-09
### Fixed
- Converter nullable warnings, see [#10](https://github.com/Phlegmlee/Godot-Saveable/pull/10).

## [1.2.2] - 2026-09-08
### Fixed
- Example folder name `example` was too generic, changed to prevent naming conflicts. See [#8](https://github.com/Phlegmlee/Godot-Saveable/pull/8).

### Added
- Version info was missing due to the removal of the `plugin.cfg` file. A current version header has been added to the `README` within the addons folder. Users can now see what version they have installed.

## [1.2.1] - 2026-09-08
### Added
- Example folder added to `.gitattributes`. Downloads of the add-on now include the example for optional addition to the users project.

## [1.2.0] - 2026-09-06
### Added
- `SlotManager` methods completed, see [#6](https://github.com/Phlegmlee/Godot-Saveable/pull/6).

## [1.1.0] - 2026-09-06
### Added
- Converted the plugin to just a runtime addon/library, see [#2](https://github.com/Phlegmlee/Godot-Saveable/pull/2).
- Created a small example [#3](https://github.com/Phlegmlee/Godot-Saveable/pull/3).
- Save slot feature, see [#5](https://github.com/Phlegmlee/Godot-Saveable/pull/5).

## [1.0.0] - 2026-09-06
